# Bhavesh Pabnani - Portfolio

A modern, responsive portfolio website built with Next.js, TypeScript, and Tailwind CSS.

## Features

- Responsive design with beautiful black and white theme with accent colors
- Animated sections using Framer Motion
- Interactive UI elements with GSAP
- Custom cursor effect
- Sections for About, Experience, Projects, Skills, Certifications, and Passions
- Contact form
- CV download option

## Tech Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- Framer Motion
- GSAP for advanced animations
- React Intersection Observer

## Getting Started

1. Clone the repository
2. Install dependencies

```bash
npm install
# or
yarn install
```

3. Run the development server

```bash
npm run dev
# or
yarn dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## Build for Production

```bash
npm run build
# or
yarn build
```

## Structure

- `/src/app` - Next.js app router pages
- `/src/components` - Reusable components
- `/src/styles` - Global styles
- `/public` - Static assets

## Customization

You can easily customize this portfolio by:

1. Changing colors in `tailwind.config.js`
2. Updating content in each component file
3. Adding your own images in the `/public/images` directory
4. Modifying animations in component files
